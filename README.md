# pacman

Pacman web app built with React and [Vite](https://vite.dev/).

## Available Scripts

In the project directory, you can run:

### `npm run dev` (or `npm start`)

Runs the app in development mode with hot reloading.<br />
Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

### `npm test`

Runs the tests with [Vitest](https://vitest.dev/) in watch mode. Use `npx vitest run` for a single run.

### `npm run build`

Builds the app for production to the `build` folder.

### `npm run preview`

Serves the production build locally so you can check it before deploying.

### `npm run lint`

Lints the source with ESLint. A pre-commit hook also lints staged files.
